# Qoima — прототип SaaS для производителей (демо: HAN Burger)

Запуск:
    npm install
    npm run dev        # http://localhost:5173

Сборка для Vercel: `npm run build` (папка dist), фреймворк Vite определяется автоматически.

Структура src/:
- data.js — демо-данные (продукция, 5 магазинов Астаны, 14 дней продаж, остатки, заявки, тарифы, компании)
- logic.js — прогноз: среднее за 7 дней × коэф. дня недели × (1 + страховой запас) − остаток; производство = отгрузка − склад; перераспределение излишков
- Producer.jsx — кабинет производителя (дашборд, задание в цех, план отгрузки, заявки, остатки, отчёты, магазины, продукция, сотрудники)
- Store.jsx — кабинет магазина (сводка, остатки, продажи за смену, заявка, доставка)
- Admin.jsx — суперадмин (компании, тарифы, состояние, подключение клиента)
- main.jsx — каркас, переключатель ролей; ui.jsx — компоненты; styles.css — стили
